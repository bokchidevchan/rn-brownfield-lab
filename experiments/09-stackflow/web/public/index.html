웹뷰 네비게이션 비교

화면 내용은 셋이 완전히 같습니다. 다른 것은 화면을 옮기는 방식뿐입니다.

1. plain MPA URL 마다 문서를 다시 받습니다. 서버 렌더링 웹을 웹뷰에 그대로 얹은 경우입니다. 2. plain SPA React 상태로 화면을 갈아 끼웁니다. 가장 흔한 방식입니다. 3. Stackflow 스택에 화면을 쌓습니다. 이전 화면이 살아 있습니다.
직접 해볼 것
  1. 목록을 한참 내린 뒤 상품을 누르고, 다시 뒤로 옵니다. 스크롤이 유지되나요?
  2. 화면이 바뀔 때 애니메이션이 있나요, 툭 바뀌나요?
  3. 상세 화면에서 왼쪽 가장자리를 오른쪽으로 미세요. 이전 화면이 따라오나요?
  4. 터미널에서 curl localhost:3000/__log 로 요청이 늘었는지 봅니다.
  5. 안드로이드 백 버튼을 눌러 봅니다. 셋 다 어떻게 되나요?
